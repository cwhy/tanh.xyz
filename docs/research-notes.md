# Research notes

Standalone HTML research notes and PDF manuscripts published at
[`/research-notes/`](../public/research-notes/index.html).

## Convention

- Put the collection index and published documents directly in `public/research-notes/`.
- Only commit `.html` and `.pdf` files to that public directory.
- Keep HTML notes self-contained by inlining their styles, diagrams, and interaction code when practical.
- Use short, descriptive kebab-case filenames.
- Add each published document to the collection index manually, including its format.
- Link primary sources and distinguish reported results, author claims, and original analysis.

## Media

Notes keep to `.html`/`.pdf` in the public notes directory, so videos, posters,
stills and replay data live under `public/data/demos/<note-name>/` and are
referenced with absolute paths such as `/data/demos/craftax-jev/rollout.mp4`.
An interactive replay embedded in a note fetches its JSON from there; prefer
that over a video when the reader benefits from scrubbing or inspecting values.

## Index entry pattern

HTML notes should link directly to `./descriptive-name.html`; printable manuscripts
should link directly to `./descriptive-name.pdf`.

## Unpublished archives

Keep superseded drafts in `private/research-notes/`, outside `public/`. The private directory is ignored by Git and is not included in the site build. Never link an archive from public pages; removing an index link alone does not make a public file private. The Jev note is generated by `scripts/jev_prompt_manipulation/render_advanced.py`; its CSS lives beside the renderer. The original pilot renderer writes only to the private directory.
