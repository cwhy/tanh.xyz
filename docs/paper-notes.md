# Paper notes

Standalone, interactive HTML introductions to research papers, published at
[`/paper-notes/`](../public/paper-notes/index.html).

## Convention

- Put the collection index and one self-contained HTML file per paper in
  `public/paper-notes/` so Vite publishes them at `/paper-notes/`.
- Use a short, descriptive kebab-case filename.
- Keep diagrams, styles, and interaction code inside the HTML when practical.
- Link the primary paper and implementation sources from the review.
- Treat reported results, author claims, and reviewer analysis as distinct.
